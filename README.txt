HTML → Markdown Converter
=========================

برنامج Windows لتحويل ملفات HTML/HTM، وخصوصاً الكتب العربية والفارسية،
إلى Markdown مع المحافظة على النص وبنية المصدر قدر الإمكان.

القواعد الأساسية
----------------
- UTF-8، دون تطبيع الحروف العربية/الفارسية أو الأرقام.
- H1..H6 إلى Markdown headings، وما فوق السادس إلى H6 عند ظهوره.
- "ص: رقم" إلى تعليق مخفي: <!-- صفحة رقم -->
- الفقرة المستقلة ** إلى ---
- المحافظة على الحواشي والهوامش والنصوص.
- الجداول البسيطة إلى Markdown، والمعقدة تبقى HTML.
- الصور المحلية تنسخ إلى مجلد assets؛ الصور المضمّنة Base64 تستخرج.
- الصور المفقودة تسجل كتحذير ولا تختفي بصمت.
- الروابط، القوائم، الاقتباسات، code/pre، sup/sub محفوظة.
- لا Metadata مولدة آلياً ولا تصحيح إملائي ولا إعادة صياغة.
- تقرير للمشكلات والعناصر غير المعتادة.

تشغيل المصدر
------------
python -m pip install beautifulsoup4 lxml tkinterdnd2
python html_to_markdown.py

إنشاء EXE على Windows
---------------------
شغّل build_windows_exe.bat.
سيُنشأ الملف:
dist\HTML-to-Markdown.exe

ملاحظة: PyInstaller يجب تشغيله على Windows لإنتاج Windows EXE.
